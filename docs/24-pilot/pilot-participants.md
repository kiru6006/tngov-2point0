# Pilot Participants & Operational Roles

| Participant Role | Cohort / Entity | Responsibilities | Access Credentials |
| :--- | :--- | :--- | :--- |
| **Citizens (Assisted Access)** | Visitors to 50 pilot e-Sevai centers | Discover services, request certificates, track applications. | Unauthenticated (Kiosk assisted) |
| **e-Sevai Kiosk Operators** | 50 village/taluk operators | Drive Assisted Access interface, verify citizen documents, print receipts. | Operator Kiosk Role |
| **Department Nodal Editors** | Revenue & Social Welfare staff | Propose contact changes, update room coordinates, submit G.O. updates. | Role: `nodal_officer` |
| **Department Nodal Checkers** | Revenue Joint / Deputy Secretaries | Review and verify change requests submitted by editors. | Role: `checker_officer` |
| **State Directory Admin** | TNeGA Portal Administrative Team | Approve officer transfers, publish live directory, monitor quality metrics. | Role: `state_admin` |
| **Platform SRE / Ops** | Engineering On-Call Team | Monitor latency, error rates, backups, and security events. | Infra / Admin access |
