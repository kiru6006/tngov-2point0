# Operational Dashboard Requirements & Layout

## 1. Unified SRE & Administrative Pane
The operational monitoring console aggregates telemetry across 4 quadrants:
1. **System Health & Ingress**:
   - Total requests, P50/P95 latency, 4xx/5xx error rates, uptime percentage.
2. **Contact Directory Health**:
   - Active verified officials, open vacancies, pending change requests, conflict alerts.
3. **Citizen Service & Search Demand**:
   - Top queried services (Community Certificate, Patta Chitta), zero-result query tracking.
4. **AI Citizen Assistant Reliability**:
   - Grounded accuracy percentage, citation coverage, review queue backlog, prompt injection deflection count.
