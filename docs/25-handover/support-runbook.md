# Tier 1 & Tier 2 Helpdesk Support Runbook

## 1. Common User Issue Resolution Matrix
| Issue Symptom | Probable Cause | First-Line Troubleshooting Step | Escalation Target |
| :--- | :--- | :--- | :--- |
| **Citizen cannot find service** | Non-standard search phrasing or Tanglish syntax | Guide citizen to use root Tamil term (e.g. `சாதி` or `பட்டா`) or navigate via Life-Event Cards on homepage. | Content Owner |
| **Official contact phone not connecting** | Department secretariat intercom changed | Check if an approved change request is pending in directory review queue. | Department Nodal Officer |
| **Application status not updating** | Third-party department legacy database sync delay | Confirm tracking number format (8-12 alphanumeric characters); verify department backend API status proxy. | TNeGA Technical Support |
| **AI Citizen Assistant giving generic response** | Query fell below confidence threshold | AI assistant safely provided official helpline (1100) and department portal link. Normal expected behavior. | AI Operations Lead |
