# GIGW 3.0 & WCAG 2.2 AA Design System

- **Palette**:
  - Primary Brand: TN Blue (`#004B87`)
  - Background: Neutral White / Slate 50
  - Text: Slate 900 (High contrast >= 4.5:1)
  - Alert: Amber 600 / Red 600
- **Typography**: Noto Sans Tamil + Sans-serif Unicode. Fluid mobile sizing starting at 16px.
- **Component Patterns**:
  - Life-Event Cards with Lucide icons.
  - Sticky bilingual search bar with auto-suggest.
  - Breadcrumb navigation mandatory on sub-pages.
  - Horizontally scrolling responsive data tables with frozen first column.
