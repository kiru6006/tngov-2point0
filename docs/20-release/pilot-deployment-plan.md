# Phased Pilot Deployment Plan (Phase 1)

## 1. Pilot Staging & Ingress
- **Ingress Strategy**: Cloudflare WAF + NGINX reverse proxy directing traffic to isolated pilot containers.
- **Pilot Population**:
  - TNeGA Operations Team (Supervision & Monitoring)
  - Revenue & Disaster Management Department Nodal Officers (Directory & Service Updates)
  - 50 designated e-Sevai Kiosks across Salem and Chennai districts.

## 2. Daily Pilot Cadence & Gate Checks
- **Day 1**: Baseline telemetry verification, health checks, read-only search testing.
- **Day 2-3**: Assisted Kiosk transactions, receipt printing validation.
- **Day 4-5**: Contact Directory change request and transfer execution drills.
- **Day 6-7**: Citizen AI Assistant query auditing via administrative review queue.
