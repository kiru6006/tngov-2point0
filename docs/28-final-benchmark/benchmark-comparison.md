# Tri-State Government Portal Benchmark Comparison Matrix

| Benchmark Dimension | Andhra Pradesh (`ap.gov.in`) | Telangana (`telangana.gov.in`) | Uttar Pradesh (`up.gov.in`) | Tamil Nadu 2.0 Consolidated Design |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Philosophy** | Action-oriented, dynamic SPA, direct MeeSeva actions | Institutional structure, documents, constitutional pillars | Citizen-friendly categories, notice board, emergency help | Unified citizen gateway combining all three philosophies |
| **Primary Menu Items** | Home, Services, Districts, Departments, e-Gov | Home, Govt, Departments, Districts, Documents, Initiatives | Home, About UP, Govt, Services, Schemes, Notices, Directory | **Home, Citizen Services, Schemes, Government, Depts & Districts, Directory, Documents, More** |
| **Service Discovery Mode** | Inline Service Action Panel (instant reveal on selection) | Department directory hierarchy | Category cards linking to secondary lists | **Inline Service Action Panel (AP pattern) + 14 Mega Menu categories + Life Situations** |
| **Service Detail Page** | Standardized MeeSeva specification (Fee, SLA, Track) | Summary with redirect to department site | Brief description with application link | **18-Field Comprehensive Specification (Eligibility, Docs, SLA, Fee, Mode, Apply, Track, Charters)** |
| **Contact Directory** | Searchable public servants list | Static departmental contact tables | Departmental contact numbers | **P0 Real-Time Contact Directory with Maker-Checker governance, Transfer history, Vacancies & Search** |
| **District Architecture**| 26 District portals with collectorates | 33 Districts directory | 75 Districts table | **38 Districts Interactive Explorer + Full District Administration Architecture** |
| **Government Structure** | Departmental listing | Strict Executive, Legislature, Judiciary separation | Executive leadership emphasis | **Three Constitutional Pillars (Executive, Legislature, Judiciary) cleanly separated** |
| **G.O.s & Documents** | G.O. repository search | Extensive G.O. portal with search filters | Tabbed Notice Board (GOs, Circulars, Tenders) | **Tabbed Notice Board (UP pattern) + Advanced G.O. Search with Machine-Readable status** |
| **Application Tracking** | Integrated MeeSeva tracker | Department-specific tracking | Jansunwai grievance tracker | **Unified Application & Grievance Tracker hooked to e-Sevai & CM Helpline 1100** |
| **Bilingual Localization**| English & Telugu | English & Telugu | English & Hindi | **100% Equal English & தமிழ் Typography with zero unlabelled icons** |
| **Accessibility Compliance**| Standard web layout | Standard government layout | GIGW Font Sizer (A-, A, A+) & High Contrast | **WCAG 2.2 AAA Contrast (Black & #ffff00) + GIGW Dynamic Root Font Scaler + Screen Reader landmarks** |
